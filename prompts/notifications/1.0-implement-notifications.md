## Work items (in order)

### A. Service layer
1. In `src/Services/NotificationService.php` add:
   ```php
   /** @return int rows written */
   public function broadcast(string $message, string $type = 'admin_announcement', array $targets = ['role:admin'], ?string $excludeUserId = null): int
   ```
   - Resolve recipients via a single PDO query per target kind then `array_unique`:
     - `role:admin|rescuer|resident` → `SELECT id FROM users WHERE role = ? AND account_status = 'active'` (only active recipients get announcements).
     - `all` → `SELECT id FROM users WHERE account_status = 'active'`.
     - `user:<uuid>` → that single id (validate uuid shape).
   - Exclude `$excludeUserId` (the sender) so an admin doesn't notify themselves.
   - Insert with batch prepared statement (one row per recipient) using `Database::uuidV4()` ids, `is_read=FALSE`, `NOW()`.
   - Return count written. (0 is valid when a role has no active users.)
