## Context (read first)

- Stack: vanilla PHP 8.3 CLI-served app, NO framework, NO frontend build step for pages. Pages are PHP-rendered HTML; JavaScript is interactivity-only islands (`<script type="module">` loading from the esm.sh import map already emitted by `public/includes/site-head.php`, e.g. `lucide`). NEVER add npm runtime deps, bundlers, React/Vue, or new CDN packages.
- The landing page is `public/includes/homepage.php`, served at `/` by `public/index.php`. It defines `$pageTitle/$pageDescription/$pageCss` then requires `__DIR__ . '/site-head.php'` and `__DIR__ . '/header.php'`.
- Its stylesheet is `public/landing/css/landing.css`, which `@import`s numbered partials from `public/landing/css/partials/` (`01_container.css`, `02_stepper-marker.css`). New styles follow this pattern: one numbered partial per section, imported from `landing.css` in order. Plain CSS only — do NOT put Tailwind utility classes in homepage.php (the compiled Tailwind bundle purges `.php`-only classes).
- Fonts: `site-head.php` supports an optional `$fontsHref` override (Google Fonts `<link>` URL); default is Nunito. The design system font is **DM Sans** — set `$fontsHref` accordingly in homepage.php.
- Icons render via lucide hydration: `<i data-lucide="icon-name"></i>` in PHP, hydrated client-side.
- Design tokens (`docs/study/DESIGN_SYSTEM.md`) are the color/type source of truth: primary green `#3D7432`, secondary `#F6F6F6`, white, tertiary soft gray `#E8E4E4`; background accents dark blue `#1A1A2E`, black, sage green `#B6C0B4`; font DM Sans.
- `AGENTS.md` contains a **Responsive frontend (hard rule)** section — it applies fully to this unit.

## Responsive requirements (hard rule from AGENTS.md)

- Mobile-first CSS: base styles = 375px; enhance upward with `min-width` media queries at standard steps (e.g. 768px, 1024px, 1440px).
- Zero horizontal overflow at 375px. No fixed-width containers/columns — use `%`, `max-width`, `clamp()`, `fr`/`minmax()` grids, `flex-wrap`.
- Images/media scale with containers (`max-width: 100%; height: auto`). Nav stays usable at 375px.

3. `GET http://127.0.0.1:8000/` returns 200 and contains the expected section markers.
4. Load `/` in a browser at **375px**, **768px**, **1440px**: layout matches the reference proportionally, no horizontal scrollbar, nav usable, images not distorted. Confirm via devtools device toolbar, not assumption.
5. Lucide icons hydrate (no empty `<i>` gaps after load); header links navigate correctly.
