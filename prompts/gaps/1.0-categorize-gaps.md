## Per-gap row format

- **Status**: use the exact doc legend: 🟡 Partially implemented · 🎨 UI-only stub · ⚙️ Backend-only · ❌ Not implemented · or "Bug: …" for mismatches/redirects.

- **Priority**: P0 (breaks an existing screen / runtime error) / P1 (blocks a documented requirement) / P2 (nice-to-have polish).
- **Suggested fix**: concrete and bounded.
