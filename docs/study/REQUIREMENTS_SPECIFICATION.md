# FurEscue — Requirements Specification

## Functional Requirements

### 1. For Community Users (Reporters / Adopters)

- Register and log in to the system.
- Report stray, injured, or abandoned animals with location (GIS-enabled).
- Upload photos or videos for reports.
- View available animals for adoption.
- Submit adoption requests.
- Receive notifications on report and adoption status.
- Access educational content on responsible pet ownership.

### 2. For Administrators (City Vet / Rescuers)

- Manage animal reports (view, verify, update status).
- Manage animal profiles (create, edit, delete records).
- Manage adoption requests (approve/reject applications).
- View GIS heatmaps of reported cases.
- Generate reports and analytics.
- Send notifications and updates to users.

### 3. For System (Automated Functions)

- Process geotagging-based location mapping.
- Track animal lifecycle (Reported → Rescued → Under Care → Adopted).
- Generate statistical reports (adoption trends, rescue rates).
- Trigger alerts and notifications in real time.
