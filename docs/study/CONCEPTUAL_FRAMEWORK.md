# FurEscue — Conceptual Framework

## 1.6 Conceptual Framework

The conceptual framework of FURescue follows the Input–Process–Output (IPO) model as presented in Figure 1. This model illustrates how the system collects data, processes it, and turns it into useful information for both the users and the administrators.

**Input.** The system gathers data from users and administrators. This includes rescue reports, adoption applications, health records, and location details. These inputs serve as the starting point for all system activities.

**Process.** The system organizes and analyzes the gathered data. It validates the information to avoid duplicates and uses geotagging to map incidents. The system also handles the matching of pets with adopters and manages the 3D profiling and e-learning modules.

**Output.** The system produces organized results. Users see interactive maps, adoption updates, and digital animal profiles. Administrators receive analytical reports and a dashboard to monitor rescue operations in real time. This structured flow ensures that animal welfare management in Mati City becomes more efficient and data-driven.
